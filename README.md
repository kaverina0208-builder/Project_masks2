Проект "Project masks"

---

## Описание:
Проект реализует новые возможности для личного кабинета клиента. 
Это виджет, который показывает несколько последних успешных 
банковских операций клиента. 
Также есть функция сортировки операций по дате исполнения.

---

## Установка:
1. Клонируйте репозиторий:
```
git@github.com:kaverina0208-builder/Project_masks.git
```
2. Установите зависимости:
```
pip install -r requirements.txt

```

___
## Использование:
В файле ***processing.py*** 
находятся функции для исполнения задач, поставленных при создании проекта. 
В переменную ***accepted_list*** введите неободимую Вам для обработки информацию об операциях.
Добавлен модуль ***generators.py*** с новыми функциями. Функция ***filter_by_currency*** фильтрует 
все транзакции в списке по интересуещей валюте. Функция ***transaction_descriptions*** возвращает описание
необходимого количества операций. Функция ***card_number_generator*** генерирует номер карты в заданном диапазоне чисел.
Добавлен модуль ***decorators.py***. Реализован декоратор для логирования результата работы функции. 
Записи логирования можно сохранять в указанный файл, или выводить в консоль. 
___
## Тестирование:
В папке ***tests*** находятся модули с тестами для применяемых в проекте функций. 
Тесты подтверждают корректность работы функций, а также проверяют их на различные ситуации. 
Обработаны случаи ввода некорректного номера счета или карты, отсутствия каких-либо данных, 
а также случаи написания различных форматов даты.
В модуль ***test_generators.py*** добавлены тесты, подтверждающие 
корректную работу новых функций при различных входных данных.
В модуль ***test_decorators.py*** дбавлены тесты для проверки работы декоратора - 
как при корректных данных, так и при возникновения ошибки в декорируемой функции.
